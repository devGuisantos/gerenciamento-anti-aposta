# `components/ui/` — vendored shadcn primitives

Generated by `npx shadcn@latest add <component> -y`. Configured in `components.json`: style
`radix-nova`, Radix base, Lucide icons, CSS variables, neutral base (overridden by our palette in
`app/globals.css`).

## Rules

- This is **vendored code**. Edit a file here only to change the design system for the whole app —
  never to satisfy one screen. A one-off tweak goes in the `className` at the call site; a
  repeated pattern becomes a wrapper in `src/shared/ui/`.
- Never put domain knowledge here. A component that knows what a bet, a consent, or a streak is
  belongs in `src/shared/ui/` or the feature folder.
- Prefer regenerating over hand-patching when upgrading. If you must edit, leave a comment saying
  what was changed and why, so the next `add` does not silently revert it.
- These files import `cn` from `"cn"` and use `data-slot` attributes for styling hooks — keep both
  conventions if you add a component by hand.
- Some carry `"use client"` (`Label`, `Checkbox`) because Radix needs it. That does not make the
  importing page a Client Component — never add `"use client"` to a page just to use one.

## Style notes for this preset

- Sizes are compact: `Button`/`Input` default to `h-8`, `size="lg"` is `h-9`. Callers pass
  `className="h-10"` for primary form controls and hero CTAs.
- `Card` draws its edge with `ring-1 ring-foreground/10` rather than a border, which on our coffee
  surfaces reads as a soft creme outline.
- Ghost/outline hover states use `bg-muted`, not `bg-accent` — `--accent` is free for the azul
  detail colour.
