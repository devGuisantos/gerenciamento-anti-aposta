# `components/ui/` — vendored shadcn primitives

Generated by `npx shadcn@latest add <component> -y`. Configured in `components.json`: style
`radix-nova`, Radix base, Lucide icons, CSS variables, neutral base (overridden by our palette in
`app/globals.css`).

## Rules

- This is **vendored code**. Edit a file here only to change the design system for the whole app —
  never to satisfy one screen. A one-off tweak goes in the `className` at the call site; a
  repeated pattern becomes a wrapper in `src/shared/ui/`.
- Never put domain knowledge here. A component that knows what a bet, a consent, or a streak is
  belongs in `src/shared/ui/` or the feature folder.
- Prefer regenerating over hand-patching when upgrading. If you must edit, leave a comment saying
  what was changed and why, so the next `add` does not silently revert it.
- These files import `cn` from `"cn"` and use `data-slot` attributes for styling hooks — keep both
  conventions if you add a component by hand.
- Some carry `"use client"` (`Label`, `Checkbox`) because Radix needs it. That does not make the
  importing page a Client Component — never add `"use client"` to a page just to use one.

## Style notes for this preset

- Sizes are compact: `Button`/`Input` default to `h-8`, `size="lg"` is `h-9`. Callers pass
  `className="h-10"` for primary form controls and hero CTAs.
- **`CardHeader` is a grid, and `Card` is `overflow-hidden`** — which together clip rather than
  truncate. A grid item defaults to `min-width: auto`, so a header row will not shrink below its
  own text no matter how many `truncate`s are inside it: the row grows past the card and the
  right-hand element (a badge, an action) gets sliced in half. Put `min-w-0` on the direct child of
  `CardHeader` as well as on every wrapper down to the text, then `truncate` on the text itself.
  This has bitten the savings-goal cards once already.
- `Card` draws its edge with `ring-1 ring-foreground/10` rather than a border. **Local change:** we
  added `shadow-sm dark:shadow-none`, because in light mode card and page are both white and the
  ring alone gave no separation; in dark mode the card surface is already lighter than the page, so
  a shadow would only muddy the edge. The comment in `card.tsx` says the same — keep both if you
  re-add the component.
- Ghost/outline hover states use `bg-muted`, not `bg-accent` — `--accent` is free for the azul
  detail colour.
- `Slider` spreads every prop onto the root, which is a plain span; the thumb is the element with
  `role="slider"`, so an accessible name left on the root reaches no screen reader. **Local
  change:** the wrapper pulls `aria-label`/`aria-labelledby` out and forwards them to each thumb.
  The comment in `slider.tsx` says the same — keep both if you re-add the component. Its thumb is
  also `size-3` with an `after:-inset-2` hit area, under the 36px touch target, so callers on
  touch-first screens enlarge it in `className`.
